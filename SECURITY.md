# Security policy

## Reporting a vulnerability

Never open a public issue for a security problem. Report it privately instead, from the repo's
**Security** tab under **Report a vulnerability**. Expect an acknowledgement within 3 business days.

Leaked credentials or tokens in the repo or its history count as security issues too.

## Supported versions

Only `main` (the deployed site) gets fixes.

## Rights-holder takedown requests

Rights holders who want material removed should open a private advisory or contact a maintainer
listed in `.github/CODEOWNERS`. We remove the material first and discuss afterwards. See
[docs/data-and-assets.md](docs/data-and-assets.md#takedowns).
